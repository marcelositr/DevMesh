# Registros de decisões

Esta pasta registra decisões importantes do DevMesh e seus fundamentos. O objetivo é manter um histórico compreensível sem duplicar discussões, políticas ou documentação técnica.

## Decisões registradas

- [0001: modelo inicial de governança](0001-initial-governance-model.md): estabelece a governança inicial conduzida pela pessoa responsável pelo projeto, com participação comunitária gradual e regras para mudanças relevantes.
- [0002: adoção do Eclipse Mosquitto](0002-adoption-of-eclipse-mosquitto.md): seleciona o Mosquitto como broker MQTT da arquitetura inicial, sem afirmar que já foi implantado ou testado.

## Como registrar uma decisão

1. Verifique se a decisão é importante o suficiente para precisar de registro duradouro.
2. Use o próximo número sequencial e um nome de arquivo curto, descritivo e estável.
3. Documente contexto, alternativas consideradas, decisão, consequências, riscos e estado.
4. Linke discussões e documentos relacionados em vez de copiar seu conteúdo.
5. Se a decisão mudar, registre a revisão e explique o que mudou, sem apagar silenciosamente o histórico.

Use estados claros, como **proposta**, **aceita**, **substituída** ou **rejeitada**. Não registre uma hipótese como decisão aprovada.
