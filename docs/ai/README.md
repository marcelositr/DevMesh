# Contexto de trabalho para ferramentas de IA

Esta pasta contém notas para ajudar ferramentas de IA a retomar o trabalho no DevMesh. Ela não substitui a documentação oficial nem concede autoridade para alterar decisões por conta própria.

## Regras de uso

- Consulte primeiro o [README principal](../../README.md), a [governança](../../GOVERNANCE.md), o [guia de contribuição](../../CONTRIBUTING.md) e os documentos relevantes em [docs](../README.md).
- Trate os arquivos desta pasta como contexto auxiliar, não como fonte superior às políticas e decisões registradas.
- Separe fatos verificados, decisões aprovadas, hipóteses, tarefas pendentes e testes não executados.
- Não declare que um arquivo foi alterado, que um teste passou ou que uma configuração está ativa sem evidência verificável.
- Não invente acessos, contatos privados, infraestrutura, recursos ou resultados.
- Antes de modificar arquivos, confira a versão atual do repositório e preserve alterações recentes.
- Mantenha a documentação voltada à comunidade em português brasileiro; mantenha o código e os identificadores técnicos conforme as convenções do ecossistema, normalmente em inglês.
- Nunca inclua tokens, senhas, chaves privadas, códigos de recuperação ou outros segredos nesta pasta.

**Atenção:** se o repositório estiver público, tudo nesta pasta também estará público. Não use este diretório para informações privadas ou segredos.
